# サイト構成・2026-11-02 ChatGPT作業記録

ユーザーの指定により、ツールはteruluce/teru-toolsに集約し、https://teruluce.github.io/teru-tools/ を専用トップにする。元のduck-address-generatorは削除対象。teruluce.github.ioはディズニー系の入口とAbout Meに使う。

個人モデルの生成り・グリーンのデザインを基に、8ツールと共通ナビ、公開向け説明・SEOを配置。Duckmailの公開版入力検証・メールアプリ連携を保持する。各ツールのcanonical、OGP、Twitter、サイトマップは新しい/teru-tools/のURLを指す。

ツール本体の編集先はこのリポジトリの各フォルダ。個人側の氏名・メール・LINEは移植しない。星座の共有URL・履歴とラリーのlocalStorageについて利用者に説明。

移転元のduck-address-generatorは公開ファイルを削除して終了する。リポジトリ自体の削除は接続APIが対応せず、GitHub Settingsからユーザー操作が必要。旧teruluce.github.io/toolsの公開URLは固定の新URLへ転送する。

検証: Chromiumの375/768/1440px幅、各ツールの主要操作、URLクリーナーの6テスト、XMLサイトマップ、公開用URLと内部リンクを確認する。iPhone/iPad実機の共有・バックグラウンド通知、検索エンジンのインデックスは未検証。

このリポジトリはコードの配置先。GitHub Pagesの設定はリポジトリのSettings→Pagesでmainの/(root)を公開元に指定する。連携APIがPages設定に対応しない場合はユーザー操作が必要。
